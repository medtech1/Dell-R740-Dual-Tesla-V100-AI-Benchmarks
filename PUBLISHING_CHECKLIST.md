- [ ] Choose a repository name, add a description and optionally an open license.
- [ ] Verify there are no private addresses, credentials, host tokens, or model weight files (none intentionally included).
- [ ] Keep the original RTX 2080 SUPER R740 repository unchanged; link both projects.
- [ ] Check chart labels and caveats, especially CLI vs llama-bench, different workloads, and single-GPU ComfyUI video.
